# buncombeairbnb
a map showing the different types of Airbnb listings in Buncombe County

this map was our example map for a practice on changing points and how they appear on the map with different classifications. All data had already been provided to me and it didn't take very long to make. it also uses polygons to show the amount per district in the area. 

Base Map is from Leaflet and the Asheville zoning districts come from the City of Asheville Open Data, and AirBNB data from Inside Airbnb. Both Data sets were provided through my class but that's where they come from. 

Written mostly in CS for actions, with heavy HTMl use for the regular showings.
